# Direction contract

## THESIS

A dense aviation-weather menu should feel immediately scannable on a phone: one level of hierarchy at a time, with the full map inventory available without changing visual language. The prototype now compares disclosure-in-place with a dedicated drill-in screen.

## OWN-WORLD

Inherit the supplied product world rather than inventing a new one: deep navy working surfaces, near-black chrome, cyan controls, lime category labels, yellow focus and account accents, compact wrapping destination chips, and map-like colour swatches.

## STORY

The shared link opens a minimal phone-sized launcher with two choices: Accordion and Drilling. Each choice opens the same navigation content in its respective journey; closing either returns to the launcher. The custom accordion implementation remains an unlinked internal test route.

## FIRST VIEWPORT

At 390 × 844, the initial frame shows only Open menu, Accordion, Drilling, and the persistent Crown copyright footer. Each journey then shows the menu title and close control, search and profile controls, six top-level sections, and the footer. In the drill-in version, opening Map replaces the root with a vertically scrollable grouped inventory whose Back/title bar remains pinned. Desktop shows the same centered mobile frame without research controls or descriptive copy.

## FORM

Operate mode. Use semantic disclosure, button/panel, or history-backed screen structures; 44px-class targets; visible and restored focus; restrained state motion; no horizontal overflow; and no decorative surfaces that compete with navigation. Visible Back and browser Back must lead to the same root state.

## Seed reference

The three screenshots supplied with the request are the visual seed and authority. This is a narrow extension of an established surface, so no new-world concept seed applies.
