# Quality bar

- Faithfully preserve the supplied navigation hierarchy and palette.
- Launch from a minimal two-option Accordion/Drilling screen.
- Keep custom JavaScript available internally but absent from participant UI.
- Show only the centered mobile frame on desktop.
- Include every one of the 26 supplied Map player types.
- Keep one top-level section open at a time in both implementations.
- Preserve open section and query when switching implementations.
- Give every drill-in category a replacement screen with persistent Back and title.
- Make visible Back and browser Back restore the originating category focus.
- Support keyboard operation, accurate states, visible focus, and reduced motion.
- Keep mobile document width equal to viewport width.
- Make long panels scroll without displacing the persistent footer.
- Use no dependencies or build step.
